# v0.9.0 Continuous Split-Screen Solve

Goal: turn the Android flow into one capture authorization per solve session instead of one authorization per screenshot.

Flow:

1. Open Water Sort Solver and tap **Start split-screen solve**.
2. Android grants one MediaProjection session.
3. Put Water Sort Solver and the game in split screen.
4. Tap **Continuous capture** whenever the board needs to be re-read.
5. The opposite pane is cropped locally, sent into the existing recognizer, and solved by the existing Web Worker.
6. End the capture session explicitly when finished.

Privacy invariants:

- Captures remain in app-private cache.
- No broad media/storage permission is requested.
- No screenshot is uploaded to a backend.
- The foreground MediaProjection notification stays visible while the continuous session is active.
- The session is stopped when the user taps **End capture**, Android revokes projection, or the service is destroyed.
